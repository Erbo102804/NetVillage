# 📊 Отчет о разработке веб-приложения NetVillage

## 📋 Общая информация

**Название проекта:** NetVillage - Интернет для села
**Период разработки:** Декабрь 2024
**Технологический стек:**
- Backend: Django 4.2 + Django REST Framework
- Frontend: React 18 + Vite
- База данных: SQLite (разработка) / PostgreSQL (продакшн)
- Аутентификация: Token-based (DRF)
- Стилизация: Custom CSS

---

## 🎯 Цели и задачи проекта

Разработка полнофункционального веб-приложения для предоставления интернет-услуг в сельской местности с возможностью:
- Просмотра тарифных планов
- Регистрации и авторизации пользователей
- Управления корзиной покупок
- Оформления заказов
- Администрирования через Django Admin

## ✅ Реализованный функционал

### 1. Backend (Django)

#### 1.1. Приложение `basket` (Корзина покупок)

**Модели:**
- `Basket` - корзина пользователя или анонимной сессии
  - Поддержка авторизованных пользователей
  - Поддержка анонимных пользователей через session_key
  - Автоматический расчет общей стоимости

- `BasketItem` - элементы корзины
  - Связь с тарифами
  - Количество (quantity)
  - Период подписки в месяцах (months)
  - Автоматический расчет стоимости: `price × quantity × months`

**API Endpoints:**
```
GET    /api/basket/              - Получить корзину пользователя
POST   /api/basket/add/          - Добавить товар в корзину
GET    /api/basket/item/<id>/    - Получить элемент корзины
PUT    /api/basket/item/<id>/    - Обновить элемент корзины
DELETE /api/basket/item/<id>/    - Удалить элемент корзины
DELETE /api/basket/clear/        - Очистить всю корзину
```

**Ключевые особенности:**
- Валидация данных через сериализаторы DRF
- Логирование всех операций
- Обработка ошибок с понятными сообщениями на русском языке
- Поддержка как авторизованных, так и анонимных пользователей

#### 1.2. Модуль `authentication` (Аутентификация)

**Функционал:**
- Регистрация пользователей с расширенным профилем (7+ полей)
- Вход/выход из системы
- Получение профиля пользователя
- Token-based аутентификация

**Поля регистрации:**
1. `username` - Имя пользователя (обязательное)
2. `email` - Email (обязательное)
3. `password` - Пароль (обязательное)
4. `password_confirm` - Подтверждение пароля (обязательное)
5. `first_name` - Имя (обязательное)
6. `last_name` - Фамилия (обязательное)
7. `phone` - Номер телефона (обязательное)
8. `city` - Город (обязательное)
9. `address` - Адрес (необязательное)

**API Endpoints:**
```
POST /api/auth/register/  - Регистрация нового пользователя
POST /api/auth/login/     - Вход в систему
POST /api/auth/logout/    - Выход из системы
GET  /api/auth/profile/   - Получить профиль пользователя
```

**Безопасность:**
- Валидация паролей (минимальная длина, сложность)
- Хеширование паролей
- Проверка уникальности username и email
- Защита от CSRF атак

#### 1.3. Интеграция существующих приложений

**Приложение `tariffs`:**
- Управление тарифными планами
- API для получения списка тарифов
- Модели с описанием, ценой, скоростью

**Приложение `orders`:**
- Создание заказов из корзины
- Отслеживание статуса заказов
- История заказов

**Приложение `payments`:**
- Обработка платежей
- Интеграция с платежными системами
- Отслеживание статуса оплаты

#### 1.4. Административная панель (Django Admin + Jazzmin)

**Настройки:**
- Красивый современный интерфейс (тема Darkly)
- Кастомизированные иконки для каждой модели
- Dashboard со статистикой:
  - Общее количество заказов
  - Общая сумма доходов
  - Количество ожидающих заказов
- Поиск по моделям
- Фильтрация и сортировка
- Inline редактирование связанных объектов

**Зарегистрированные модели:**
- User (Пользователи)
- Tariff (Тарифы)
- Order (Заказы)
- Payment (Платежи)
- Basket (Корзины)
- BasketItem (Элементы корзины)

#### 1.5. Конфигурация (settings.py)

**Установленные приложения:**
```python
'jazzmin',                      # Красивая админка
'django.contrib.admin',
'rest_framework',               # REST API
'rest_framework.authtoken',     # Token auth
'corsheaders',                  # CORS для React
'payments', 'tariffs', 'orders', 'basket'
```

**REST Framework настройки:**
- JSON рендерер по умолчанию
- Token + Session аутентификация
- Пермишены для защищенных эндпоинтов

**CORS настройки:**
- Разрешенные origins: localhost:3000, 127.0.0.1:3000
- В режиме DEBUG разрешены все origins
- Поддержка credentials

**Безопасность:**
- SECRET_KEY из переменных окружения
- DEBUG режим конфигурируется через .env
- ALLOWED_HOSTS настраиваются через переменные окружения
- Валидаторы паролей

**Локализация:**
- Язык: Русский (ru-ru)
- Часовой пояс: Asia/Almaty
- Включена интернационализация

## 🔧 Технические особенности

### Backend

1. **RESTful API Design**
   - Консистентные URL структуры
   - HTTP методы (GET, POST, PUT, DELETE)
   - Статус коды (200, 201, 400, 404, 500)
   - JSON формат ответов

2. **Сериализация данных**
   - DRF Serializers для валидации
   - Nested serialization (тарифы внутри корзины)

   - Custom validators

3. **Управление сессиями**
   - Поддержка анонимных пользователей
   - Миграция корзины при авторизации
   - Session middleware

4. **Логирование**
   - Запись всех операций с корзиной
   - Отдельные файлы логов
   - Разные уровни (DEBUG, INFO, ERROR)

5. **Безопасность**
   - CSRF защита
   - CORS настройки
   - Password validators
   - Token expiration

### Frontend

1. **State Management**
   - React Context API для глобального состояния
   - Local state для компонентов
   - localStorage для персистентности

2. **Performance**
   - Vite для быстрой сборки
   - Lazy loading компонентов
   - Debounce для поиска
   - Мемоизация вычислений

3. **UX/UI**
   - Немедленный feedback пользователю
   - Loading состояния
   - Error boundaries
   - Валидация форм в реальном времени

4. **Accessibility**
   - Семантический HTML
   - ARIA атрибуты
   - Keyboard navigation
   - Читаемые сообщения об ошибках

## 🚀 Развертывание и запуск

### Требования
- Python 3.9+
- Node.js 16+
- npm или yarn
- SQLite (разработка) / PostgreSQL (продакшн)

### Backend
```bash
# Активация виртуального окружения
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Миграции базы данных
python manage.py makemigrations
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Загрузка тестовых данных
python manage.py loaddata tariffs/fixtures/initial_tariffs.json

# Запуск сервера
python manage.py runserver
```

### Frontend
```bash
# Переход в директорию frontend
cd frontend

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build
```
