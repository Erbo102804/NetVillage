# 🚀 Инструкция по запуску React приложения NetVillage

## Шаг 1: Подготовка backend

### 1.1. Активируйте виртуальное окружение

```bash
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 1.2. Выполните миграции для новых моделей

```bash
# Создайте миграции для корзины
python manage.py makemigrations basket

# Примените все миграции
python manage.py migrate
```

### 1.3. Создайте суперпользователя (если еще нет)

```bash
python manage.py createsuperuser
```

### 1.4. Загрузите тестовые данные

```bash
python manage.py loaddata tariffs/fixtures/initial_tariffs.json
```

### 1.5. Запустите Django backend

```bash
python manage.py runserver
```

Backend должен быть доступен на **http://localhost:8000**

---

## Шаг 2: Установка и запуск React frontend

### 2.1. Перейдите в директорию frontend

```bash
cd frontend
```

### 2.2. Установите Node.js (если еще не установлен)

Скачайте и установите Node.js с официального сайта: https://nodejs.org/
Рекомендуемая версия: v18 или выше

Проверьте установку:

```bash
node --version
npm --version
```

### 2.3. Установите зависимости

```bash
npm install
```

Это установит все необходимые пакеты:
- react
- react-dom
- react-router-dom
- axios
- vite
- и другие...

### 2.4. Создайте .env файл

```bash
cp .env.example .env
```

Или создайте `.env` файл вручную с содержимым:

```env
VITE_API_URL=http://localhost:8000/api
```

### 2.5. Запустите development сервер

```bash
npm run dev
```

Frontend будет доступен на **http://localhost:3000**

- **/order/update/:id** - Редактирование заказа

## Шаг 5: API Endpoints

### Авторизация

- `POST /api/auth/register/` - Регистрация
- `POST /api/auth/login/` - Вход
- `POST /api/auth/logout/` - Выход
- `GET /api/auth/profile/` - Профиль пользователя

### Корзина

- `GET /api/basket/` - Получить корзину
- `POST /api/basket/add/` - Добавить в корзину
  ```json
  {
    "tariff_id": 1,
    "quantity": 1,
    "months": 3
  }
  ```
- `PUT /api/basket/item/{id}/` - Обновить элемент
  ```json
  {
    "quantity": 2,
    "months": 6
  }
  ```
- `DELETE /api/basket/item/{id}/` - Удалить элемент
- `DELETE /api/basket/clear/` - Очистить корзину

### Тарифы и заказы

- `GET /api/tariffs/` - Список тарифов
- `POST /api/orders/` - Создать заказ

## Возможные проблемы

### 1. Django не запускается

```bash
# Убедитесь, что виртуальное окружение активировано
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Frontend не запускается

```bash
# Удалите node_modules и установите заново
rm -rf node_modules package-lock.json
npm install
```

### 3. CORS ошибки

Убедитесь, что в `backend/settings.py` есть:

```python
CORS_ALLOW_ALL_ORIGINS = DEBUG  # True для development
```

### 4. API не отвечает

Проверьте, что Django запущен на порту 8000:

```bash
curl http://localhost:8000/api/health/
```

Должно вернуть:

```json
{"status": "OK", "message": "NetVillage API is running"}
```

## Поддержка

Если возникли проблемы:

1. Проверьте консоль браузера (F12)
2. Проверьте логи Django в терминале
3. Убедитесь, что оба сервера запущены (Django + Vite)
4. Очистите localStorage в браузере
5. Проверьте, что все миграции применены
